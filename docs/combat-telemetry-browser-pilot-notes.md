# 본게임 자동 플레이 파일럿

## 조건

- 표준 난이도, 유전 보너스 없음
- 장기별 고정 이동 정책과 0.7초 액션 시도
- 목표 장기의 각성 카드를 우선하고, 각성 뒤에는 해당 직업 증강을 우선
- 브라우저 본게임의 적 생성, 충돌, 피해, 카드 확률을 그대로 사용
- 표본은 장기별 1회이므로 방향성 판정용이며 최종 수치 조정 근거로 사용하지 않는다.

## 판정

1. **각성 전 성장 속도가 직업 결과를 크게 좌우한다.** 같은 기본 투사체 상태인데도 목표별 이동 정책에 따라 경험치 수급 차이가 크게 났다. 폐는 별도 1차 런에서도 92.26초에 미각성 사망해 같은 문제가 반복됐다.
2. **근육의 처치 성능이 매우 높다.** 간보다 DPS는 낮지만 처치 수는 약 1.94배이고 정상 시간에 가까운 413.41초에 클리어했다. 충돌 계열이 다수전을 지나치게 잘 정리하는지 추가 표본이 필요하다.
3. **간은 총 피해가 가장 높지만 보스 마무리가 느리다.** 장판과 파열 피해는 강하지만 최종 보스에 516.36초가 걸렸다. 총 DPS만으로 강약을 판단하면 오판하기 쉽다.
4. **뇌는 각성 뒤에도 회복하지 못했다.** 수정된 자동 선택 정책에서 `사고 폭주` Lv.2를 얻었지만 0보스, 255.34초에 종료됐다. 코어와 연쇄의 실제 명중·단일 대상 효율을 우선 점검해야 한다.
5. **심장은 액션 의존도가 높다.** `heart_action`이 전체 피해의 약 50.4%다. 자동 액션 주기가 수동 숙련 플레이보다 유리할 수 있는데도 클리어하지 못했으므로 최종 구간 생존과 근접 위험을 확인할 가치가 있다.

## 다음 검증

- 장기별 최소 5회까지 반복해 각성률, 중앙 생존시간, 클리어율을 계산한다.
- 폐는 각성 전 3번째 레벨 도달률과 도달 시간을 별도 지표로 기록한다.
- 뇌는 코어 명중률과 보스 대상 DPS, 근육은 충돌 1회당 동시 처치 수를 추가 기록한다.
- 플레이 정책 영향을 분리하기 위해 원거리 직업의 목표 거리 200/250/300 비교군을 둔다.
