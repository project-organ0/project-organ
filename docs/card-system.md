# 증강 시스템 기획 및 현재 구현 평가

작성일: 2026-08-08  
평가 기준: `app/organ-game.tsx`의 `CLASS_CARDS`, `weightedChoices`, `cardLevel(...)` 전투 로직과 `app/game/augment-catalog.json`, `app/game/augment-selection.js`

## 1. 문서 목적

이 문서는 현재 구현된 직업 증강의 카드 명세와 실제 동작을 대조하고, 레벨별 효과와 구조적 결함을 확인하기 위한 기준 문서다. 현재 구현 평가를 바탕으로 T1이 최상위이고 T4가 최하위인 1차 티어 분류도 관리한다.

새로운 증강 추가와 확률 조정은 아직 이 평가 범위에 포함하지 않는다. 먼저 현재 증강의 빈 레벨, 설명 불일치, 과도하거나 불명확한 동작을 정리한 뒤 티어 분류와 확장 기획을 진행한다.

## 2. 현재 증강 구조

- 장기: 심장, 뇌, 간, 폐, 근육의 5종
- 직업 증강: 장기별 4개, 총 20개
- 트리 구조: 선행 증강 2개에서 각각 연결된 후속 증강 1개가 열리는 2갈래 구조
- 최대 레벨: 모든 직업 증강 Lv.3
- 각성 전 카드 풀: 장기 성장 60 / 생활 20 / 공용 20
- 각성 후 카드 풀: 현재 직업 증강 45 / 장기 성장 25 / 생활 15 / 공용 15
- 직업 증강은 선행 증강을 획득해야 연결된 후속 증강이 등장한다.
- 현재 가중치는 카드 종류별 풀에만 적용된다. 같은 트리, 이미 획득한 증강, 플레이어 레벨에 따른 추가 가중치는 없다.

### 장기 정체성

| 장기 | 한 문장 정체성 | 핵심 루프 | 강점 | 약점 |
| --- | --- | --- | --- | --- |
| 심장 | 위험한 근접전을 빠른 연타와 처치 가속으로 돌파하는 격투가 | 접근 → 연타 → 피니시 → 처치 가속 | 단일 대상, 순간 폭발 | 근접 유지 위험 |
| 뇌 | 여러 코어가 표적을 자동 판단하고 연쇄 공격하는 에너지술사 | 코어 사격 → 자동 표적 → 연쇄 → 추가 일제 사격 | 안정적인 원거리 공격 | 밀집 대응과 기동성 |
| 간 | 이동 경로를 독 지대로 바꾸고 중첩과 전염으로 전장을 장악하는 독술사 | 장판 생성 → 중첩 → 중독 → 파열·전염 | 지역 장악, 다수전 | 즉발 피해 |
| 폐 | 멈추지 않는 이동을 공격과 회피 자원으로 바꾸는 질풍술사 | 이동 → 모멘텀 → 이동 공격 → 가속 유지 | 회피, 이동 공격 | 정지 시 전투력 감소 |
| 근육 | 강타와 넉백으로 적을 모으거나 충돌시켜 한 번에 무너뜨리는 파괴자 | 충전 → 강타 → 넉백 → 충돌 | 범위 폭발, 군중 제어 | 공격 간격과 선딜레이 |

## 3. 증강별 명세 검토

이 단계에서는 증강의 강함과 약함을 평가하지 않는다. 성능 차이는 추후 희귀도 티어와 등장 확률을 설계할 때 함께 다룬다. 현재 검토 기준은 다음 세 가지로 제한한다.

- **명세 일치**: 카드 설명과 실제 전투 동작이 같은가.
- **레벨 성장**: Lv.1~3에서 실제 전투 효과가 달라지는가.
- **구조 문제**: 무한 증가, 빈 레벨, 기본 능력과의 경계 충돌처럼 수치 조정만으로 해결되지 않는 문제가 있는가.

### 심장: 격투가

| 증강 | 실제 동작 | 명세 일치 | 레벨 성장 | 구조 문제 |

| 심박 충격 | 4번째 공격이 범위 피해를 준다. 레벨마다 범위와 피해가 증가하며 Lv.3은 적에게 다음 타격 피해를 높이는 심장 표식을 남긴다. | **일치** | **있음**: 범위, 피해, Lv.3 표식이 단계적으로 적용된다. | 없음 |
| 과부하 연타 | 같은 적을 5회 타격하면 해당 타격이 `2.2배`가 된다. 레벨마다 모든 근접 피해가 8%씩 증가한다. | **일치** | **부분적**: 기본 근접 피해는 증가하지만 5타 조건과 과부하 배율은 동일하다. | 없음 |
| 혈류 가속 | 근거리 처치 시 `2/3/4초` 동안 이동 속도가 `20/25/30%` 증가한다. | **일치** | **있음**: 지속시간과 이동 속도가 함께 증가한다. | 없음 |

## 4. 빈 레벨 보완 결과

이번 보완으로 기존 빈 레벨 7개에 다음 성장을 적용했다.

| 증강 | Lv.1 | Lv.2 | Lv.3 |
| --- | --- | --- | --- |
| 혈류 가속 | 2초 · 이동 +20% | 3초 · 이동 +25% | 4초 · 이동 +30% |
| 집중 사고 | 엘리트·보스 +20% | +40% | +60% |
| 사고 폭주 | 5킬마다 발동 | 4킬마다 발동 | 3킬마다 발동 |
| 오염 중첩 | 최대 3중첩 | 최대 4중첩 | 최대 5중첩 |
| 농축 독 | 1초마다 중첩 | 0.75초마다 중첩 | 0.5초마다 중첩 |
| 순환 가속 | 2초 · 이동 +20% | 3초 · 이동 +25% | 4초 · 이동 +30% |
| 중력 압박 | 범위 1.5배 · 당김 80 | 범위 1.75배 · 당김 110 | 범위 2배 · 당김 140 |

오염 중첩은 현재 중첩이 최대치보다 낮을 때만 반경이 15% 증가한다. 각 레벨의 최대 반경은 기본 반경 `74`를 기준으로 약 `98/113/130`이며, 생활 카드의 독 범위 배율은 그 이후 별도로 적용된다.

위 수치는 빈 레벨을 제거하기 위한 1차 기준이다. 성능 등급과 최종 수치는 추후 희귀도 티어 및 확률 테이블과 함께 평가한다.

## 5. 증강 역할 분류

각 증강에는 가장 지배적인 역할 하나를 부여한다. 여러 역할을 일부 수행하더라도 카드 선택 이유를 가장 잘 설명하는 역할을 기준으로 분류한다.

| 역할 | 정의 |
| --- | --- |
| 핵심 강화 | 장기의 기본 전투 루프를 더 자주 또는 더 강하게 수행하게 한다. |
| 약점 보완 | 장기의 명시된 약점을 완화하되 완전히 제거하지는 않는다. |
| 조건부 폭발 | 처치, 연타, 중첩, 최대 모멘텀처럼 조건을 달성했을 때 큰 보상을 준다. |
| 구조 변화 | 기존 행동을 새로운 공격, 범위 효과 또는 군중 제어로 바꾼다. |

| 장기 | 증강 | 역할 | 정체성과의 연결 |
| --- | --- | --- | --- |
| 심장 | 아드레날린 | 핵심 강화 | 근접 유지에 빠른 공격 주기를 제공해 연타 루프를 직접 강화한다. |
| 심장 | 심박 충격 | 구조 변화 | 4번째 기본 공격을 범위 피니시와 표식 공격으로 바꾼다. |
| 심장 | 과부하 연타 | 조건부 폭발 | 같은 대상을 5회 공격했을 때 강한 단일 대상 보상을 준다. |
| 심장 | 혈류 가속 | 약점 보완 | 근거리 처치 후 이동 속도를 높여 재접근과 위험 이탈을 돕는다. |
| 뇌 | 시냅스 증식 | 핵심 강화 | 자동 공격 코어 수를 늘려 뇌의 기본 공격 체계를 직접 확장한다. |
| 뇌 | 연쇄 사고 | 약점 보완 | 코어 탄환을 추가 대상에게 연결해 기본 원거리 공격의 밀집 대응을 보완한다. |
| 뇌 | 집중 사고 | 핵심 강화 | 자동 표적 판단을 강한 적 우선으로 정교화하고 해당 대상 피해를 높인다. |
| 뇌 | 사고 폭주 | 조건부 폭발 | 연속 처치를 모든 코어의 추가 일제 사격으로 전환한다. |
| 간 | 독성 발자국 | 핵심 강화 | 이동 경로에 생성되는 독 지대의 빈도와 지속시간을 높인다. |
| 간 | 오염 중첩 | 조건부 폭발 | 같은 경로를 다시 지나는 조건을 지대 중첩과 면적 증가로 보상한다. |
| 간 | 독성 파열 | 구조 변화 | 중독된 적의 죽음을 범위 피해와 중독 전염의 시작점으로 바꾼다. |
| 간 | 농축 독 | 핵심 강화 | 독 지대 체류를 더 빠른 중독 중첩으로 연결한다. |
| 폐 | 칼바람 | 구조 변화 | 이동 거리를 관통 투사체 발사로 전환해 이동 자체를 공격으로 만든다. |
| 폐 | 잔상 호흡 | 조건부 폭발 | 높은 모멘텀을 유지했을 때 이동 잔상에 지속 피해를 부여한다. |

| 근육 | 과잉 수축 | 핵심 강화 | 기본 강타의 범위와 넉백을 높여 강타 루프를 직접 강화한다. |
| 근육 | 연쇄 충돌 | 구조 변화 | 넉백된 적의 충돌을 주변 범위 피해로 확장한다. |
| 근육 | 고통 연료 | 약점 보완 | 근접전에서 받은 피해를 다음 강타의 충전으로 전환한다. |
| 근육 | 중력 압박 | 구조 변화 | 강타 전에 적을 끌어모아 느린 범위 공격의 적중 효율을 바꾼다. |

### 정체성 판정

| 장기 | 판정 | 남은 위험 |
| --- | --- | --- |
| 심장 | **양호**: 접근, 연타, 피니시, 처치 후 이동이 하나의 근접 루프로 이어진다. | 현재 최상위 빌드 변화 카드가 없다. |
| 뇌 | **양호**: 코어 수, 표적 판단, 연쇄, 일제 사격이 자동 원거리 공격을 일관되게 강화한다. | 집중 사고는 대상 제한 때문에 다른 카드보다 체감이 약할 수 있다. |
| 간 | **양호**: 장판, 중첩, 중독, 사망 파열이 명확한 연쇄 구조를 만든다. | 네 카드의 시너지가 강하게 곱해져 완성 빌드의 성능 급증 가능성이 높다. |
| 폐 | **양호**: 모든 카드가 이동과 모멘텀 유지에 직접 연결된다. | 정지 시 약점이 매우 선명해 실제 조작 난이도에 따라 성능 편차가 커질 수 있다. |
| 근육 | **양호**: 강타, 넉백, 기본 충돌, 증강으로 추가되는 범위 폭발과 당김이 일관된 파괴자 루프를 만든다. | 고통 연료가 의도적인 피격을 과도하게 장려하는지 확인해야 한다. |

역할 분포는 핵심 강화 7개, 약점 보완 4개, 조건부 폭발 4개, 구조 변화 5개다. 현재 구성에는 역할이 없는 카드가 없으며, 모든 증강이 각 장기의 핵심 루프 또는 명시된 약점에 연결된다.

## 6. 확정 티어 분류

티어 숫자가 낮을수록 상위 등급이다. 티어는 카드 트리의 선행·후속 관계와 별개이며, 현재 효과의 전투 영향, 빌드 구조 변화, 발동 조건과 범용성을 함께 평가한다.

티어는 현재 수치가 큰 순서가 아니라 카드가 담당하는 설계 역할을 기준으로 확정한다. 같은 티어 안에서 과도하게 강하거나 약한 수치는 이후 밸런스 단계에서 조정하며, 수치가 크다는 이유만으로 구조 변화가 없는 카드를 T1으로 올리지 않는다.

| 티어 | 판정 기준 |
| --- | --- |
| T1 | 런의 전투 구조를 바꾸거나 완성된 빌드의 성능을 크게 증폭하는 효과 |
| T2 | 장기의 핵심 전투 루프를 직접 강화하거나 강한 시너지를 만드는 효과 |

## 7. 티어 등장 확률

각성 후 선택지에서 직업 증강 풀이 선택될 기본 가중치 `45%`는 유지한다. 아래 표는 전체 카드 선택 확률이 아니라 직업 증강 풀이 선택된 뒤 해당 티어가 나올 조건부 확률이다.

| 진행 구간 | 적용 조건 | T1 | T2 | T3 | T4 |
| --- | --- | ---: | ---: | ---: | ---: |
| 각성 직후 | 스테이지 1, Lv.5 이하 | 0% | 5% | 30% | 65% |
| 중반 | 스테이지 2 이상 또는 Lv.6 이상 | 3% | 15% | 37% | 45% |
| 후반 | 스테이지 3 이상 또는 Lv.8 이상 | 8% | 27% | 38% | 27% |
| 최종 | 스테이지 4 또는 Lv.10 이상 | 15% | 35% | 30% | 20% |

스테이지와 플레이어 레벨 중 더 앞선 구간을 사용한다. 현재 해금되고 최대 레벨에 도달하지 않은 카드만 후보가 되며, 특정 티어에 후보가 없으면 그 티어의 확률은 나머지 가능한 티어에 비례 재분배한다.

### 보장 규칙

- 보스 처치 후 `전투 증강`에는 가능한 경우 T3 이상 직업 증강을 최소 1장 포함한다.
- 각성 후 4회의 카드 제안에서 T2 이상을 보지 못하면 5번째 제안에 가능한 T2 이상 직업 증강을 최소 1장 포함한다.
- T2 이상 카드가 제안되면 천장 누적을 초기화한다.
- 보장 카드 한 장을 먼저 배치한 뒤 남은 칸은 기존 직업 45 / 장기 성장 25 / 생활 15 / 공용 15 가중치로 채운다.
- 해금 및 최대 레벨 상태 때문에 보장 등급 카드가 하나도 없으면 빈 선택지를 만들지 않고 일반 규칙으로 대체한다.
- 같은 선택지 안에는 동일 카드가 중복되지 않는다.

직업 증강 카드에는 `T1~T4` 배지를 표시하고 티어마다 카드 상단선과 배지 색을 구분한다. 티어 확률과 보장 수치는 `app/game/augment-balance.json`에서 관리한다.

## 8. 기존 빌드 갈래 가중치

직업 증강 후보의 기본 가중치는 해당 진행 구간의 티어 확률을 같은 티어의 후보 수로 나눈 값이다. 여기에 이미 선택한 빌드와의 관계에 따라 다음 보정을 곱한다.

| 조건 | 배율 |
| --- | ---: |
| 획득한 카드와 같은 갈래 | 1.35배 |
| 이미 획득한 동일 카드의 레벨업 | 1.15배 |
| 두 조건이 함께 적용될 때 | 최대 1.5배 |
| 같은 갈래를 2회 이상 연속 선택한 뒤 해당 갈래 | 1.15배로 완화 |
| 아직 선택하지 않은 반대 갈래 | 1배 유지 |

가중치는 티어 확률로 만든 카드별 기본 가중치에 곱한다. 따라서 같은 갈래의 후속 카드가 다른 티어에 있어도 실제 등장 확률이 증가하지만, 최대 보너스를 제한해 상위 티어 확률이 지나치게 왜곡되지 않게 한다.

연속 선택 횟수는 직업 증강을 선택했을 때만 갱신한다. 생활, 공용, 장기 성장 카드를 사이에 선택해도 직전 직업 갈래 기록은 유지하며, 반대 갈래 직업 증강을 선택하면 연속 횟수가 새 갈래 기준으로 초기화된다.

같은 갈래 배율 `1.0/1.25/1.35/1.5`를 각 직업 2,000회씩 동일 시드로 비교했다. `1.0 → 1.35`에서 전체 갈래 완성률은 `88.4% → 88.8%`, 반대 갈래 제시율은 `58.8% → 58.8%`로 변했다. 현재 4카드·2단 트리에서는 영향이 작고 선택 다양성을 훼손하지 않으므로 `1.35`를 미세 보정값으로 확정한다. 상세 결과는 `docs/augment-branch-weight-comparison.md`에 기록한다. 설정값은 `app/game/augment-balance.json`의 `branchWeighting`에서 관리한다.

## 9. 명세 및 구조 결정

### 9.1 아드레날린

실제 공격 주기를 기준 명세로 사용한다. 근처에 적이 있으면 공격 간격이 `30/35/40%` 감소하며 공격 범위는 변경하지 않는다.

카드 설명과 효과 문구도 이 계산에 맞춘다. 수치의 강약은 T2 재검증 단계에서 별도로 판단한다.

### 9.2 연쇄 충돌

적끼리 충돌할 때 충돌한 두 적에게 발생하는 공격력의 140% 피해와 충돌 연출은 파괴자의 기본 능력으로 유지한다.

연쇄 충돌 증강은 주변 적에게 공격력의 80% 추가 피해를 주는 범위 폭발을 해금한다. 레벨은 추가 폭발 반경을 `88/114/141`로 증가시킨다. 카드 설명은 기본 충돌이 아니라 이 추가 폭발을 안내한다.

## 10. 스킬 연출 구현

기존 직업별 4×2 스킬 시트를 재사용해 증강 레벨이 전투 화면의 형태 변화로 이어지게 했다. 순간 연출은 짧게 유지하고 지속 상태는 낮은 불투명도의 선과 범위 표시로 구분한다.

| 장기 | 구현한 시각 언어 |
| --- | --- |
| 심장 | 심박 충격 Lv.2부터 돌진 펀치에 확장 충격파, Lv.3에 회전 표식 레이어 추가 |
| 뇌 | 시냅스 증식과 연쇄 사고에 따라 코어 연결선의 형태·굵기 변화, 상위 레벨 액션에 회전 코어 레이어 추가 |
| 간 | 오염 중첩과 농축 독 레벨에 따라 독성 영역 액션에 외곽 농도·회전 핵 레이어 추가 |
| 폐 | 칼바람 레벨에 따른 이동 풍압 궤적 수 증가, 태풍의 눈 레벨에 따른 대시 회오리 수·크기 변화 |
| 근육 | 강타 충전량과 중력 압박 레벨을 상시 반경으로 표시하고 액션에 수축·폭발 링 추가 |

데스크톱 디버그 직업 5종에서 기본 상태와 SPACE 액션을 확인했다. 연출은 적과 지형을 완전히 가리지 않으며, 캔버스는 키보드 포커스를 받을 수 있도록 설정했다.

## 12. 현재 결론

기존 빈 레벨 7개에는 모두 실제 전투 성장이 적용됐고, 오염 중첩의 무제한 반경 증가도 제거됐다. 아드레날린의 표시 문구와 연쇄 충돌의 기본 능력·증강 능력 경계도 실제 동작에 맞게 확정했다.

장기별 전투 정체성과 20개 증강의 역할을 확정했다. 현재 증강은 모두 장기의 핵심 루프나 약점에 연결되며 다섯 장기 모두 현재 구성의 정체성이 양호하다.

현재 20개 증강은 T1 4개, T2 8개, T3 4개, T4 4개로 기획 등급을 확정했다. 등급은 카드의 설계 역할을 나타내며, 같은 등급 안의 최종 성능 수치는 등장 확률과 실제 플레이 결과를 함께 보고 조정한다.

각성 후 직업 카드에는 진행 구간별 티어 확률이 실제 적용되며, 보스 T3 이상 보장과 5회차 T2 이상 천장을 사용한다. 카드 선택 화면에서도 현재 티어를 직접 확인할 수 있다.

이미 선택한 증강과 같은 갈래에는 1.35배, 동일 카드 레벨업에는 1.15배 가중치를 적용하며 합산 보너스는 1.5배로 제한한다. 같은 갈래를 연속 선택하면 보너스를 완화해 반대 갈래의 기본 확률을 보존한다.

증강 수치의 상대적인 성장폭은 별도의 [헤드리스 밸런스 시뮬레이션](balance-simulation.md)으로 반복 검증한다. 현재 카드 선택 구조 기준 실행 결과는 `balance-simulation-2026-08-09.md`와 원시 결과 JSON에 보관한다.
