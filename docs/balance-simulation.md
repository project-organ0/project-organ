# 헤드리스 밸런스 시뮬레이션

## 1. 목적

`scripts/full-run-balance-sim.mjs`는 브라우저를 조작하지 않고 전체 런을 반복해 직업과 증강 레벨 사이의 상대적인 성능 차이를 찾는 도구다.

주 용도는 증강의 Lv.1~3 성장폭 비교, 급격하거나 비어 있는 성장 구간 탐지, 직업별 큰 편차 확인, 밸런스 변경 전후 비교다. 결과는 실제 클리어율의 확정적인 예측값이 아니라 수치 조정 후보를 선별하는 1차 평가 자료로 사용한다.

## 2. 게임 코드와의 관계

시뮬레이터는 본게임의 Canvas 렌더링 및 입력 루프와 분리되어 있다. 본게임에 자동 플레이, 시드 고정, 시뮬레이션 전용 상태를 추가하지 않는다.

두 실행 환경은 `app/game/augment-balance.json`의 밸런스 수치, `app/game/augment-catalog.json`의 카드 구조, `app/game/augment-selection.js`의 추첨 계산을 함께 참조한다.

## 3. 런 진행 모델

한 런은 최대 480초이며 0.5초 단위로 계산한다. 각 시간 단계는 다음 순서로 진행된다.

1. 현재 시간에 따라 스테이지와 스테이지 진행 시간을 결정한다.
2. 본게임의 증가식을 기준으로 적 상한, 스폰율, 적 체력을 계산한다.
3. 포아송 분포로 이번 시간 단계에 추가될 적 수를 정한다.
4. 직업, 카드 레벨, 적 밀집도로 DPS, 보스 배율, 피격 계수를 계산한다.
5. 일반 적과 보스에게 피해를 배분하고 처치 결과를 반영한다.
6. 처치 경험치로 레벨업과 카드 선택을 진행한다.
7. 남은 적과 보스로부터 받는 전투 압력을 체력 피해로 환산한다.
8. 플레이어 사망, 제한시간 도달, 최종 보스 처치 중 하나가 발생하면 종료한다.

적은 개별 좌표 객체가 아니라 `적 수`, `전체 잔여 체력`, `보스별 체력`, `화면 밀집도`로 집계한다. 따라서 많은 횟수를 빠르게 반복할 수 있다.

### 카드 선택 모델

- `augment-catalog.json`의 20개 카드, 부모 해금 조건, T1~T4를 그대로 사용한다.
- 선택지는 본게임과 같은 3장이며 각 슬롯의 직업 카드 풀 기본 비중은 45%다.
- 보스 선택의 T3 이상 보장과 5회 누적 보장의 T2 이상 규칙을 적용한다.
- 선택 AI는 이미 획득한 카드의 레벨업, 현재 계열, 높은 티어 순으로 직업 카드를 고른다.
- 티어별 평균 획득량, T1 획득 확률과 최초 시점, 계열 완성률, 고유 카드 노출 수, 반복 제시율을 기록한다.

## 4. 직업별 전투 프로필

`combatProfile(...)`은 현재 카드 상태를 거시 전투 수치로 변환한다.

| 직업 | 주요 반영 요소 |
| --- | --- |
| 심장 | 아드레날린 공격 주기, 과부하, 심박 충격, 혈류 가속 가동률 |
| 뇌 | 코어 수, 연쇄 사고, 집중 사고의 보스 배율, 사고 폭주 발동 빈도 |
| 간 | 독 지대 면적, 오염 중첩, 독성 파열, 농축 독 중첩 주기 |
| 폐 | 칼바람, 태풍의 눈, 잔상 호흡, 순환 가속 가동률 |
| 근육 | 강타, 연쇄 충돌, 고통 연료, 중력 압박의 범위와 당김 거리 |

직업별 프로필은 평균 DPS와 피격 위험을 계산하기 위한 근사식이며 실제 플레이 결과로 보정해야 한다.

## 5. 실험 종류

### 5.1 자연 진행 비교

각 장기를 목표 직업으로 지정해 전체 런을 반복한다. 각성 전에는 목표 장기를 우선하며, 각성 후에는 실제 확률로 구성된 선택지에서 보유 카드 레벨업과 기존 계열을 우선한다.

직업별 클리어율, 생존시간, 처치량, 보스 처치 수, 도달 레벨과 각성 시간을 비교한다.

### 5.2 증강 한계효과 비교

평가 대상 증강만 Lv.0~3으로 변경하고 같은 직업의 다른 증강은 Lv.1로 고정한다. 레벨마다 동일한 난수 시드를 사용해 우연한 스폰 차이를 줄인다.

Lv.0 대비 Lv.3의 생존·처치 변화, 각 레벨의 추가 처치량, 특정 레벨에서 발생하는 클리어율 임계점을 확인한다.

## 7. 실행과 출력

기본 실행:

```bash
npm run balance:simulate
```

조건 지정:

```bash
npm run balance:simulate -- --runs=5000 --seed=20260808 --difficulty=normal --out=docs/balance-simulation-candidate
```

실행하면 같은 경로에 사람이 읽는 비교표와 자동 판독을 담은 `.md`, 조건과 모든 집계값을 담은 `.json`을 생성한다. 현재 카드 선택 구조 기준 결과는 `docs/balance-simulation-2026-08-09.md`와 `docs/balance-simulation-2026-08-09.json`에 보관한다.

## 8. 해석 원칙

- 강한 증강이라는 이유만으로 문제로 판정하지 않고 티어별 획득 빈도와 함께 평가한다.
- 절대 클리어율보다 같은 조건에서의 직업 및 레벨 간 상대 차이를 우선한다.
- 클리어율이 급격히 변하면 생존시간과 처치량도 함께 확인한다.
- Lv.1→2와 Lv.2→3의 증가폭이 지나치게 급격하거나 거의 없는지를 확인한다.
- 수치 확정 전 실제 플레이 결과로 직업별 기준 DPS와 피격 계수를 보정한다.

## 9. 모델의 한계

현재 모델은 Canvas 좌표와 개별 충돌, 투사체의 실제 명중·관통·낭비, 적 종류별 행동, 플레이어 이동과 순간 회피, 장판 유도와 액션 사용 시점, 화면 시인성과 조작 난이도를 직접 재현하지 않는다.

따라서 시뮬레이션만으로 최종 밸런스를 확정하지 않는다. 헤드리스 결과로 이상 구간을 찾고 해당 구간을 실제 플레이에서 재검증하는 순서로 사용한다.
